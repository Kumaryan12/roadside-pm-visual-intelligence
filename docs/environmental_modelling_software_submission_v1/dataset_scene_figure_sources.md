# Dataset scene figure provenance

`figures_submission_final/Figure_02_dataset_scene_examples.png` is a montage of
representative input frames from the two public datasets evaluated in the
manuscript. Frames were uniformly converted to grayscale and cropped for
layout. A uniform contrast adjustment was applied; no objects or semantic
content were added or removed.
