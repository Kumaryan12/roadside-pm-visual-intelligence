# Internal revision response

This memo records how the critical-review points were addressed in the revised
submission. It is an internal preparation document, not a response to an
editorial decision.

1. **Software novelty.** The title, abstract, introduction, related work and
   Methods now define the contribution as an executable contract joining grouped
   sequence construction, raw-context auditing, background provenance,
   group-restricted fitting and group-aware inference. A new workflow table maps
   each stage to public command-line modules and auditable outputs.
2. **Taiwan signal attribution.** The matched background, context and complete
   estimator rows now appear together in the main results. The text identifies
   the task as monitoring-network-assisted local refinement and reports the
   paired six-site uncertainty of the final increment.
3. **TRAQID grouped performance.** The abstract, cross-dataset summary and
   conclusion report pooled, mean date-wise, median date-wise and positive-date
   results together.
4. **Retrospective status.** The chronological Taiwan analysis is consistently
   described as retrospective grouped validation with a frozen final scoring
   pipeline, not prospective confirmation.
5. **Grouped uncertainty.** The main text distinguishes the 5,000 date-cluster
   resamples from the 20,000 six-site resamples and explains that repeated
   resampling does not increase the number of spatial units.
6. **Background dependence.** Existing one-hour-lag and single-support-site
   outage analyses remain central. TRAQID distance/tolerance sensitivity is
   explicitly identified as prospective follow-up rather than claimed without
   results.
7. **Sensor uncertainty.** Limitations now distinguish grouped sampling
   uncertainty from target-instrument error and note the SDS011 and missing
   Taiwan monitor metadata.
8. **Presentation.** The central component table is in the main text, figures
   use the grayscale set, and the cover letter/highlights use the revised
   software-method framing.

During verification, a provenance mismatch was corrected: the Taiwan
complete-date bootstrap used 5,000 replicates, while the six-site bootstrap used
20,000. The revised manuscript now matches the preserved artifacts.
