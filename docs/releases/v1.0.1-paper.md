# v1.0.1 — Zenodo archival release

This metadata-only follow-up republishes the paper submission snapshot after
the repository was connected to Zenodo. The scientific results, manuscript,
figures, and software are unchanged from `v1.0.0-paper`.

## Included

- Leakage audits for overlapping temporal image windows.
- Complete-date, chronological, and held-out-site evaluation workflows.
- Background-conditioned visual and contextual PM2.5 modelling pipelines.
- TRAQID and Taiwan experiment configurations and provenance documentation.
- Environmental Modelling & Software manuscript source, grayscale figures,
  graphical abstract, highlights, cover letter, and compiled manuscript.

## Reproducibility scope

Large model weights, raw images, downloaded public data, embeddings, caches,
and per-row prediction dumps are intentionally excluded. Source datasets must
be obtained from their original providers under their own licences and access
conditions.
