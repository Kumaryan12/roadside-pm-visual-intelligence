# v1.0.0 — paper submission snapshot

This release freezes the reproducible software and manuscript materials for:

**Auditing Temporal-Context Leakage in Image-Based PM2.5 Estimation: A
Background-Conditioned Framework for Grouped Prediction**

## Included

- Leakage audits for overlapping temporal image windows.
- Complete-date, chronological, and held-out-site evaluation workflows.
- Background-conditioned visual and contextual PM2.5 modelling pipelines.
- TRAQID and Taiwan experiment configurations and provenance documentation.
- Environmental Modelling & Software manuscript source, grayscale figures,
  graphical abstract, highlights, cover letter, and compiled review manuscript.

## Reproducibility scope

The repository contains code, configurations, aggregate results, split audits,
and manuscript assets. Large model weights, raw images, downloaded public data,
embeddings, caches, and per-row prediction dumps are intentionally excluded.
Source datasets must be obtained from their original providers under their own
licences and access conditions.

## Validation note

Random overlapping-window results are diagnostic and are not claims of unseen
date or site generalization. Reportable evaluations use the grouping and
availability assumptions stated in the manuscript and experiment provenance.
