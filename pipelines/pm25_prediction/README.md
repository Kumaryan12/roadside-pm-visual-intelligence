# PM2.5 prediction pipeline

Canonical objective: predict PM2.5 from inference-safe image, vehicle, road,
geospatial, meteorological, and temporal features under grouped, purged,
chronological, and spatially blocked validation.

Existing TRAQID and MUMMA scripts remain the historical implementations while
this pipeline is assembled and checked for result equivalence.

The first compatibility migration is available at `mumma_281/run.py`.
