# PM2.5 prediction experiments

New experiments should contain only a config, short rationale, and compact
result summary. Large artifacts belong under `artifacts/runs/<run_id>/`.

The canonical TRAQID generalized image/residual experiment is registered in
`configs/pipelines/traqid_outer_crossfit_v1.yaml` and executed by
`pipelines/image_embeddings/traqid_outer_crossfit.py`.
